# Portfolio Pulse AI — HTML + JSON Portable v3

## New in this version
- Edit holdings directly: add/remove stocks, quantity, average cost, current price, currency, name.
- Browser localStorage persistence in static/offline mode.
- Export Portfolio JSON and CSV.
- Dashboard Portfolio Value chart with 1D, 1W, 1M, 3M, YTD, 1Y, 5Y, ALL.
- 1Y sparkline for every holding row.
- Click any ticker to open Asset Detail.
- Asset price chart with 1D, 1W, 1M, 3M, YTD, 1Y, 5Y, ALL.
- No external chart library or CDN dependency.

Historical charts use embedded/cached history when present. If no real historical dataset is connected, the UI labels the fallback as demo-generated rather than live.

Open `index.html` directly, or deploy the folder as a static website.
